# Day 2 – Data Cleaning in Excel

## 1. Topics Practised

- Identifying duplicate records
- Removing duplicate values using Remove Duplicates
- Identifying missing values
- Handling missing salary values using NA
- Removing extra spaces using TRIM()
- Capitalizing words using PROPER()
- Extracting patterns using Flash Fill
- Standardizing location values
- Splitting text into separate columns using Text to Columns
- Creating helper columns for data cleaning

## 2. Excel Functions Practised

| Function | Purpose |
|---|---|
| TRIM() | Removes unnecessary spaces |
| PROPER() | Capitalizes the first letter of each word |
| IF() | Applies logical conditions |
| SEARCH() | Finds text within another text |

## 3. Excel Tools Practised

- Remove Duplicates
- Flash Fill (Ctrl + E)
- Text to Columns

## 4. Practical Work

Used the Data Analyst Job Market dataset to practise data cleaning.

- Checked the dataset for duplicate records. Excel reported no duplicates.
- Worked with missing salary values.
- Used TRIM() and PROPER() to clean text.
- Created helper columns for standardized locations.
- Practised extracting job-type information using Flash Fill.
- Split the Skills Mentioned column into separate columns using Text to Columns.
- Kept the original columns while practising transformations.

## 5. Key Learnings

- Understood why data cleaning is important before analysis.
- Learned how to identify duplicate and missing values.
- Practised cleaning inconsistent text.
- Learned how to split text into multiple columns.
- Understood how helper columns can preserve original data.
